### 週次利用51%でも「浸透」とは言い切れない──ロイター研究所2026調査で読むAI普及の現在地

「いまや2人に1人が、毎週AIを使っている」。英オックスフォード大学のReuters Institute（ロイター・ジャーナリズム研究所）が2026年10月29日に公開した調査は、そんな節目の数字を示しました。

この数字を見て、私は2つのことを考えました。1つは伸びの背景に検索エンジンなど既存サービスへの組み込み、複数サービスの使い分け、調べ物や相談といった日常利用の広がりがあるのではないかということ。もう1つは若い世代や高所得層、高学歴層、専門職で利用率が依然として高いなら、レイトマジョリティ（新しいものに慎重で、周囲が使い始めてから動く層）への浸透はまだ十分ではないのではないかということです。

<!-- 実体験：この調査に注目したきっかけや、身の回りで感じているAI利用の変化 -->

そこで、報告書のデータでこの2つの見方を確かめてみました。先に結論を書くと、各社の利用率が伸びた背景には、複数サービスの併用もありそうです。一方、**利用者そのものが増えた理由は、この調査だけでは切り分けられません**。

また、週次利用は半数を超えましたが、利用頻度や使う機能、AIに対する見方には大きな差があります。「使うか使わないか」に加えて、「**どう使うか**」という新たな格差も見えてきました。

#### 調査の概要

細かい手法は読み飛ばしても大丈夫ですが、数字を読むうえで「**6カ国平均**」と「**9カ国平均**」の違いだけは覚えておいてください。

| 項目           | 内容                                                                                        |
| -------------- | ------------------------------------------------------------------------------------------- |
| 実施           | Reuters Institute（調査実務はYouGov）                                                       |
| 調査期間       | 2026年8月14日〜9月28日                                                                      |
| 対象国         | アルゼンチン、豪州、デンマーク、フィンランド、フランス、日本、ノルウェー、英国、米国の9カ国 |
| 標本           | 各国約2,000人のオンライン調査                                                               |
| 経年比較の対象 | 3年連続で調査した6カ国（豪州、フィンランド、ノルウェーを除く）                              |

なお、報告書はオンライン調査の限界も明記しています。無作為抽出ではないため通常の誤差幅は計算できず、±2ポイント以内の差は有意である可能性が低いとされています。また、オフラインの人々（高齢、経済的に余裕が少ない、学歴が高くない傾向）の行動は反映されにくく、教育水準の高い人は多めに反映されやすくなります。この点は後半の浸透の議論に関わってきます。

#### 数字の全体像

まず全体の伸びです。週次利用は1年で17ポイント増えました。下の表は特定のAIサービスを自分で選んで使っている人の割合で、検索結果に出るAI要約を見ただけの人は含みません。

| 指標（6カ国平均）        | 2024年 | 2025年 | 2026年 |
| ------------------------ | ------ | ------ | ------ |
| 週1回以上利用            | 18%    | 34%    | 51%    |
| 毎日利用                 | 7%     | 16%    | 28%    |
| 情報を得るために利用     | 11%    | 24%    | 38%    |
| コンテンツ制作に利用     | 14%    | 21%    | 31%    |
| ニュースを得るために利用 | 3%     | 6%     | 9%     |

国別でも、前年から13〜21ポイント増えました。

| 国           | 2024年 | 2025年 | 2026年 | 前年差 |
| ------------ | ------ | ------ | ------ | ------ |
| アルゼンチン | 21%    | 51%    | 68%    | +17    |
| デンマーク   | 15%    | 34%    | 51%    | +17    |
| 米国         | 31%    | 36%    | 49%    | +13    |
| フランス     | 16%    | 27%    | 48%    | +21    |
| 日本         | 11%    | 26%    | 46%    | +20    |
| 英国         | 13%    | 28%    | 42%    | +14    |

今年から加わった3カ国は、ノルウェー57%、豪州51%、フィンランド48%でした。サービス別の週次利用を見ても、主要サービスはそろって伸びています。

| サービス（6カ国平均） | 2025年 | 2026年 | 前年差 |
| --------------------- | ------ | ------ | ------ |
| ChatGPT               | 22%    | 34%    | +12    |
| Google Gemini         | 11%    | 24%    | +13    |
| Microsoft Copilot     | 6%     | 11%    | +5     |
| Meta AI               | 9%     | 11%    | +2     |
| Claude                | 1%     | 7%     | +6     |

#### 伸びの要因を検証する

私が考えた3つの要因に、報告書自身が挙げている「仕事」を加えた4点を確かめます。

##### 既存サービスへの組み込み

組み込みの広がりはデータにはっきり出ています。9カ国平均で、直近1週間に検索エンジンでAIの回答や要約に接した人は57%です。端末や各種アプリなども含めると71%に達します。これらの数字には意図して使った分も含まれます。報告書は、本人が選ばないまま接する場合を「incidental AI exposure（偶発的なAI接触）」と呼んでいます。すごく雑に言うと、「AIを使おうと思っていないのに、検索したら出てきた」という状態です。

ただし、判断材料が割れていて、**週次利用の伸びの原因とまでは言えません**。

- 日本は検索でのAI接触が69%で9カ国中最高なのに、週次利用は46%です。逆にノルウェーは接触が48%と低めでも、週次利用は57%あります。9カ国の単純な相関を私が計算すると−0.06で、ほぼ無相関でした（国数が少ないので参考程度です）
- 検索でのAI接触は、昨年の54%に対して今年は57%でした。週次利用の17ポイント増に比べると小さな差ですが、設問の文言と対象国が違うので単純には比較できません
- 一方でフランスの検索でのAI接触は、Googleの「AI Overview」が未提供だった昨年の29%から47%へ上昇し、週次利用の伸びも+21ポイントで最大でした

フランスの例は「組み込みが入口になる」という見方と整合します。ただ、1カ国の同時期の変化なので、因果を示すものではありません。

Geminiの数字にも注意が必要です。設問では「Google検索経由を除く」と指定していますが、検索のAI Modeを使った人がこの選択肢を選んだ可能性があると、報告書は注記しています。

##### 複数サービスの使い分け

週次利用者が定期的に使うサービスは、平均で2つになったと報告書は述べています。この併用は、私が「各社の利用率が高まっている」と感じた理由の1つと考えられます。

報告書のサービス別の表（Figure 4）を単純に足すと、併用の大きさが見えてきます。以下は端数処理された公表値からの私の概算です。

| 6カ国平均                    | 2025年 | 2026年 | 増加分 |
| ---------------------------- | ------ | ------ | ------ |
| 各サービスの週次利用率の合計 | 58%    | 103%   | +45    |
| 全体の週次利用率             | 34%    | 51%    | +17    |
| 合計÷全体（1人あたりの概数） | 約1.7  | 約2.0  | ─      |

2025年は表に載っていない選択肢があるので、あくまで目安です。それでも、各社の数字を足した伸びは、利用者そのものの伸びの2倍以上あります。各社の伸びをそのまま合計して普及の勢いと読むと、**実態を過大に見積もってしまいます**。

併用で増えるのは「1人が使うサービスの数」で、「使う人の数」ではありません。全体の51%を押し上げた要因は、別に考える必要があります。

##### 調べ物や相談への広がり

日常用途の広がりは、私が考えた3つの要因の中で最もデータがそろっています。情報を得るための利用は38%で、コンテンツ制作の31%を引き離しました。用途別に見ると、トピックの調査が24%、助言が20%、事実の質問が18%、おすすめが15%です。

AIを情報目的で使う理由として、「速くて簡単に答えが得られる」を選んだ人は64%でした。一方、「他の情報源より信頼できる」は21%にとどまります。多くの人にとって、AIは「正確だから」ではなく「**手間が減るから**」使う道具になっています。また、情報目的や交流目的で使う人に聞くと、検索エンジンの利用が「減った」人は「増えた」人を差し引きで13ポイント上回っています。

ただ、この伸びの大半は利用者全体が増えたことの反映で、週次利用者に限ると用途の変化はより小さいという報告書の指摘は見逃せません。もちろん、週次利用者の中でも助言やおすすめは事実の質問や調査より速く伸びているので、日常用途へのシフト自体はあります。とはいえ、「用途が広がったから人が増えた」のか「人が増えたから用途別の数字も上がった」のかは、この調査だけでは切り分けられません。鶏と卵の問題です。

##### 仕事への組み込み

私の見立てになかった要因として、報告書は仕事を挙げています。AIの導入は特定の仕事や職場への組み込みにも一部けん引されており、職種によっては事実上「選択ではなく必須」かもしれないとの指摘です。職場や学校経由で有料版を使える人も9%います。

ここまでの検証をまとめます。

| 要因                     | データの裏付け                  | 説明できる範囲                         |
| ------------------------ | ------------------------------- | -------------------------------------- |
| 既存サービスへの組み込み | 接触71%。国別の連動は一様でない | 接点の拡大。利用増との因果は未確定     |
| 複数サービスの併用       | 週次利用者の平均は2サービス     | 各社の数字の伸び                       |
| 調べ物・相談への拡大     | 情報目的38%、助言20%            | 使い方の変化。利用者増との前後は不明   |
| 仕事への組み込み         | 職業別の差、報告書の指摘        | 一部のけん引役。寄与度は示されていない |

#### レイトマジョリティへの浸透

##### イノベーター理論と51%

エベレット・ロジャーズのイノベーター理論では、新しい技術を採用する時期によって人々を5つに分類します。その区分を累計すると、アーリーマジョリティまでが50%です。

| 区分                 | 比率  | 累計 |
| -------------------- | ----- | ---- |
| イノベーター         | 2.5%  | 2.5% |
| アーリーアダプター   | 13.5% | 16%  |
| アーリーマジョリティ | 34%   | 50%  |
| レイトマジョリティ   | 34%   | 84%  |
| ラガード             | 16%   | 100% |

今回の週次利用率51%はこの50%という境目に近い数字です。ただし、イノベーター理論は採用時期による分類であり、週次利用率をそのまま当てはめることはできません。

それでも、半数が毎週利用するようになった一方、依然として使っていない人や、利用に慎重な人が相当数いることは確かです。利用が半数を超えたからといって、**社会全体に十分浸透したと判断するのは早い**のではないでしょうか。しかも先ほど触れたように、オンライン調査には高齢層や経済的に余裕の少ない層が反映されにくいため、実態はこれより低い可能性があります。

9カ国平均で見ると、利用の濃淡も分かります。毎日使う人が26%、一度も使ったことがない人が22%で、残りの約5割はその中間です。

##### 属性ごとの差

報告書は、若い世代、所得や学歴の高い層、スキル水準の高い職業で利用が多いと述べています。ただし今年の報告書本文で具体的な数値があるのは職業のみで、年齢、所得、学歴は傾向の記述にとどまります。年齢については、昨年の調査で18〜24歳が59%、55歳以上が20%という大きな差がありました。

職業別の週次利用（9カ国平均）は次のとおりです。

| 職業分類（抜粋）             | 週次利用 |
| ---------------------------- | -------- |
| 専門職（投資アナリストなど） | 64%      |
| 管理職                       | 61%      |
| 事務補助（受付など）         | 52%      |
| サービス・販売（店員など）   | 49%      |
| 基礎的職業（清掃作業員など） | 45%      |

ここは私の予想と少し違いました。専門職と基礎的職業の差は19ポイントあり、格差は確かに存在します。ただ、**最も低い層でも45%が毎週使っている**わけで、「専門職だけのツール」という段階はすでに過ぎているようです。もちろん、回答者がオンライン調査の参加者である点は割り引いて読む必要があります。

##### 使い方の深さの差

むしろ差がはっきり開くのは使い方の深さです。AIエージェント（チャットで答えるだけでなく、複数の手順を代行するAI）を、直近1週間に実際の作業で使った人の割合を見てみます。全体では14%です。

| 比較軸       | 多い層               | 少ない層             |
| ------------ | -------------------- | -------------------- |
| 年齢         | 18〜24歳 26%         | 55歳以上 7%          |
| 利用頻度     | 毎日利用者 32%       | 週1回未満の利用者 6% |
| 有料版       | 有料アクセスあり 39% | 無料版のみ 11%       |
| 毎日利用者内 | 有料アクセスあり 50% | 無料版のみ 21%       |

有料版を使える人は全体の18%で、大半の利用者は無料版を使っています。報告書は「使うかどうか」だけでなく「どう使うか」の違いが新たな分断線になる可能性を指摘しています。週次利用率だけを見ていると、この差は見えません。

##### 非利用者の意識

もう1つ気になるのは意識の差です。AIが各分野にもたらす影響について、毎日利用者と一度も使ったことがない人の見通しの差は、**平均49ポイント**ありました。報告書によれば、この差は他のどの属性間の差よりも大きく、態度が二極化しつつある兆しもあるとされています。

イノベーター理論の曲線は、やがて多くの人が採用することを前提にしています。しかし非利用者は「遅れている人」とは限りません。まだ順番が来ていない人だけでなく、否定的な見方を強めている人もいるかもしれません。報告書自身も、利用者の増加が続くのか、利用と懐疑がどこかで頭打ちになるのかは未解決の問いだとしています。

その一方で、検索や端末へのAIの組み込みは、本人が選ばなくても進みます。「何も見ていない」と答えた人はわずか20%でした。私は、レイトマジョリティへの浸透は、自分でChatGPTを開く形よりも、使い慣れたサービスの中でいつの間にか触れている形で進むのではないかと考えています。ただ、それは「納得して使いこなしている」状態とは別物です。

#### 日本への示唆

日本の数字には特徴的な点が2つあります。

| 日本の指標                   | 数値 | 9カ国の中での位置              |
| ---------------------------- | ---- | ------------------------------ |
| 週次利用                     | 46%  | 英国に次いで低い               |
| 前年からの伸び               | +20  | 経年比較の6カ国で2番目         |
| 検索でのAI接触               | 69%  | 最高                           |
| AIとの接触（いずれかの経路） | 79%  | アルゼンチンに次いで高い       |
| 情報目的の利用               | 35%  | 米国と同率で、英国に次いで低い |

1つ目は接触と利用の開きです。検索でのAI接触と週次利用の差は23ポイントで、9カ国の中で最大でした（集計期間の定義が少し違うので、おおまかな比較です）。日本には「**AIに触れてはいるが、自分で使うところまでは進んでいない人**」が相当数いる可能性があります。

2つ目は課金です。報告書によると、ニュースへの個人課金がAIへの個人課金より多いという関係は、9カ国のうち日本だけ当てはまりません。ただしこれは日本のニュース課金の水準にも左右される話なので、AI課金が強いとまでは読めません。

ChatGPTの個人向けプランのログであるOpenAI Signalsを見ると、日本の人口あたりメッセージ量の順位は、2025年第1四半期の113位（176カ国・地域中）から2026年第3四半期の62位（173カ国・地域中）に上がりました。一方で、仕事関連メッセージの割合は2024年7月の53.2%から2026年9月の28.5%に下がり、2026年に入ってからは毎月、世界の値を下回っています。法人向けプランは対象外なので断定はできませんが、個人向けプランでの日本の伸びは、**仕事以外の利用が中心**になっている可能性があります。

企業や自治体でAI導入を担当している方にとっての実務的な意味は、利用率を1つの数字で見ないことだと思います。

- 触れている人、自分で使っている人、業務に組み込んでいる人を分けて測る
- 「導入済み」や「利用率○%」で終わらせず、利用頻度や使っている機能まで見る
- 無料版と有料版で試せることが違う前提で、研修や評価を設計する

#### まとめ

- 6カ国平均の週次利用は34%から51%へ、毎日利用は16%から28%へ増えました。ただし日本は46%で、9カ国の中では低いほうです
- 各社の伸びの背景には併用もありそうです。組み込みと日常用途の拡大も確かに進んでいますが、利用者の増加との因果はこの調査だけでは確定できません
- 週次利用は半数を超えましたが、一度も使ったことがない人も9カ国平均で22%います。オンライン調査の性質も踏まえると、浸透が十分とはまだ言えません
- 職業差は思ったより連続的でした。一方で、エージェントの活用や有料版の有無に見られる「使い方の深さ」の差は大きく開いています

利用率が50%を超えたことで、「AIを使う人を増やす」段階の次の論点が見えてきました。これからは、どれだけの人が使っているかに加えて、どこまで使いこなせているのか、そして使わない人にどう影響するのかも問われていきそうです。
